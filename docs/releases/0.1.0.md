# Full Document Reader 0.1.0

Open complete Markdown notes for Apple's Accessibility Reader on macOS and iOS.
Apple handles speech, voices and playback; the plugin supplies a read-only snapshot.

- Open the reader from the note toolbar, ribbon or command palette.
- Configure a maximum word count, initially 100,000. Over-limit notes are refused, never truncated.
- Read bundled Apple shortcut instructions in plugin settings.
- Use the platform shortcut hint after rendering; closing the reader restores workspace interaction.

Requires Obsidian 1.13+, macOS 26+ or iOS 26+ and a configured Apple accessibility shortcut.
Download `main.js`, `manifest.json` and `styles.css` into the vault's
`.obsidian/plugins/ios-tts/` directory while the plugin is disabled, then enable it.
Open a note, choose **Open full document reader**, invoke Accessibility Reader and press **Play**.

The macOS and iPhone user tests were reported passed and the reader accepted by
Taḋg on 2026-09-16. This is operator-reported validation; detailed device versions
and fixture observations were not supplied in that report.

Notes remain snapshots until reopened. Images and embeds can consume memory
independently of word count; remote resources retain normal Obsidian behaviour.
There is no speech service, audio export or EPUB/PDF conversion.
